## 维护规则

1. 新来源先分配唯一 REF-ID，再写知识切片。
2. 安全数值、维修流程和厂商指令必须绑定版本及明确定位。
3. 机器审计通过只允许写入 `origin=sourced`，不得自动写入 `verified=true`。
4. 正式 Demo 使用前须完成领域人员复核，并单独更新 Demo 来源清单。
5. 原始手册和抓取缓存不随本仓库再分发；需要复核时从官方 URL 重新取得合法副本。
