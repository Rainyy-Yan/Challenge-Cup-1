# 学习者优先前端重排设计

日期：2026-09-02

状态：已实现并完成本地验收

范围：在线入口 `server.py -> web/index.html`

## 1. 问题与目标

当前结果页把学习诊断、智能体流水线、资源全文、证据来源和反馈题同时塞进三栏，阅读顺序依赖屏幕位置而不是学习任务。模型综合描述还可能把 `<think>` 推理文本原样展示；反馈提交后只替换局部结论，没有明确的后续动作。

本次重排的目标是让学习者始终知道三件事：现在处于哪一步、当前最重要的内容是什么、接下来按哪个按钮。系统证据继续完整保留，但从主阅读层降为按需展开层。

## 2. 设计方向

采用“工业操作手册”风格，而不是通用渐变仪表盘：暖白纸面、石墨蓝文字、安全橙作步骤提示、状态绿表示已完成。标题、编号、分隔线和留白建立清晰章节感；不引入远程字体或新的前端依赖。

桌面端正文采用单一主阅读列，最大宽度约 960px。宽屏不再同时铺开三条长栏；手机端保持同一阅读顺序，不发生语义重排。

## 3. 页面信息架构

### 3.1 开始阶段

- 顶部显示四步进度：填写情况、完成测评、查看方案、练习并调整。
- “填写我的学习情况”和“查看示例方案”仍作为两种入口，但每次只展示一个入口面板。
- 生成方案后，开始区收起为一条“本次学习档案”，避免与结果争夺注意力；用户可主动展开并重新开始。

### 3.2 结果阶段

按固定纵向顺序呈现：

1. **本次学习建议**：掌握度、推荐难度、待补强数量和不超过三句的诊断摘要。
2. **建议学习顺序**：逐个知识点显示名称、目标、资源数量和当前状态。
3. **开始学习**：一次只聚焦一个知识点；资源按“要点讲义、案例、练习”分组。
4. **完成自测**：紧跟当前知识点资源之后，不再位于独立中栏。
5. **根据作答继续**：提交后展示得分、决策解释和唯一主操作。

### 3.3 证据层

- “系统如何制定方案”默认折叠，展开后显示智能体时间线。
- 每份资源默认显示标题、类型、难度、学习目标和结构化摘要。
- 完整正文按小节排版；长来源 URL 不直接铺在正文中，显示为“打开原始来源”。
- “核验与溯源”默认折叠，包含引用、人工核实状态、证据分和共识状态。

## 4. 交互与状态

### 4.1 资源导航

学习路径中的知识点是可操作导航。选择知识点后，资源区和自测区同步切换，并更新页面内的当前位置提示。

### 4.2 提交反馈

未全部作答时，在题目顶部显示可聚焦错误提示，不发送请求。提交成功后：

- 显示答对题数与总题数；
- 用中文展示 `decision.action` 对应的学习动作和原因；
- 若还有后续知识点，主按钮为“继续下一知识点”；
- 若当前知识点需要巩固，提供“重新学习本知识点”；
- 完成路径后，主按钮为“查看更新后的学习建议”；
- 自动滚动并聚焦到结果区域，使状态变化可见。

### 4.3 模型文本安全边界

后端在综合诊断进入会话数据前移除 `<think>...</think>`、未闭合 `<think>` 前缀和常见代码围栏；若清理后为空，使用规则生成的可读摘要。前端渲染前再执行轻量防御性清理，防止旧会话或异常响应泄漏推理文本。

## 5. 组件与文件边界

- `agents/examiner.py`：诊断叙述清理与规则回退，不改变诊断数值。
- `web/index.html`：重排语义结构、样式和现有原生 JavaScript；不引入框架。
- `tests/test_examiner.py`：覆盖完整、未闭合和清理后为空的思考文本。
- `tests/test_server.py`：覆盖在线页面应暴露的学习流程与后续操作契约。
- 如需浏览器级回归，新增针对实际页面行为的轻量测试，不复制生产逻辑。

## 6. 错误与可访问性

- 所有异步按钮在请求期间禁用并显示动词明确的进行状态。
- 错误提示使用 `role="alert"`；成功后的下一步区域使用可聚焦状态容器。
- 折叠区使用原生 `details/summary`；知识点导航和答题控件保留键盘可操作性。
- 颜色不作为唯一状态信号，文字和图标同时表达状态。
- 尊重 `prefers-reduced-motion`，自动滚动使用无动画回退。

## 7. 验证标准

1. 页面任何位置不显示 `<think>` 或模型推理草稿。
2. 1280px 宽度下不存在三条长文本并排；主流程可以自上而下阅读。
3. 资源正文有可辨认的标题、要点、出处层级，长链接不破坏布局。
4. 提交反馈后可见得分、决策原因和明确的下一步按钮。
5. 下一步按钮能切换到后续知识点并同步资源与测试题。
6. 390px 手机宽度下无横向溢出，按钮可触达，内容顺序不变。
7. 现有后端功能、来源核验和 400 项基线测试不回归；新增行为经历红—绿测试。

## 8. 非目标

- 不改动 BKT、检索、辩论、审核或模型路由算法。
- 不增加登录、数据库、前端框架或新的构建步骤。
- 不隐藏或删除证据，仅调整其默认展示层级。
- 不恢复任何离线版页面或浏览器端推理链。
