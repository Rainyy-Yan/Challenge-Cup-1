# P35：正式 Demo 固定题候选集

正式 Demo 不直接使用 `data/pretest.json` 的全部原题。题目若仍在改写、缺少当前
一手证据，或依赖已排除的知识切片，必须标为 `demo_eligible: false`；原题保留，
待补齐来源并经人工复核后才能恢复。

当前原题库有 47 道，正式 Demo 候选集有 40 道。被排除的题如下：

| 题号 | 排除原因 |
| --- | --- |
| Q-008 | TCP 统一毫米验收阈值无当前一手来源支撑。 |
| Q-017、Q-038、Q-041 | 分别依赖已从正式 Demo 排除的 SRVO-062、示教器急停、编码器电池资料。 |
| Q-020、Q-044 | 围栏固定高度或距离数值无当前一手来源支撑。 |
| Q-039 | 超程报警处置步骤缺少当前可定位的一手依据。 |

运行 `py -3 -m evalkit.itemreport --formal-demo` 可只生成正式候选集的题库质量
报告。该筛选不会把题目或历史记录从原题库删除。

每道保留题均已写入 `source_id`，并且只能引用允许进入正式 Demo 的切片；对应的
原始资料标题、版本、定位和人工复核栏位见
[`data/demo_item_source_manifest.json`](../data/demo_item_source_manifest.json)。题目经过
命题闸门逐题检查，保证正确答案有来源依据、引用不悬空、干扰项不与答案并存。

这不等于来源已经人工核实。台账中大多数记录仍为 `pending_manual_review`；在负责人
填写复核人、日期、结论和授权前，页面必须继续显示“待核实”。本轮仍有 4 道质量分
低于 85 的可用题，下一步应改进其干扰项，而非伪造审核结论。
